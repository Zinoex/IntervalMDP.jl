## Objective *(required)*

Run **exactly one** experiment — hypothesis **H5** from `benchmark/REPORT.md` § 7 — implement it, measure it alone
against the commit before it, and decide accept or reject. Accepted: kept as its own commit. Rejected: reverted, with
the code diff summarised in the `REPORT.md` entry. Either way the entry is written (rejected experiments stay recorded).
Measured against the head of `3f.2`.

*Measurement (Phase 0):* a ≈ 6 ms floor per synchronised call independent of size (`bellman!` median ≈ 6 ms, min
0.3–1 ms; solves ≈ 6 ms × iterations; `profiles/cuda-*.md`, `REPORT.md` § 6.3). The time is spent waiting in host
synchronisation (`CUDA.synchronize` and the device→host copy of the residual every VI iteration), not in kernels.

*Change:* remove the blocking-wait cost without changing when the loop stops: e.g. compute the residual reduction on the
device and copy one scalar (pinned memory / non-blocking copy), avoid redundant synchronisations, and/or use a spinning
instead of a yielding synchronisation (investigate CUDA.jl's synchronisation mode first and record what it is).
**Checking termination only every k iterations changes the stopping rule** (more iterations, different values) and is
out of scope — that would be an `S-<n>` Finding. Iteration counts must stay within ±1 of the merge base.

*Prediction:* 5–20× for solves of models whose kernel takes < 1 ms; `bellman!` medians close to the kernel minimum.

Adds or semantically changes a VI/Bellman algorithm: **no**. Every change computes the same result as the merge base
within the tolerances of `common.md` § Julia Behavior & Tests; anything else is raised as a Finding (`S-<n>`) and not
merged. Tier 1/2 interface changes: only additive keywords with defaults, documented; anything wider is an `I-<n>`
Finding (`common.md` § Interface Stability). Lean: if a Julia function cited by a Lean docstring is renamed, moved or
split, update the docstring in this run and keep `lake build` and `check_julia_refs.py` green.
Follow `common.md` § Context budget. Ops: push the commit(s) to `perf/phase-3` (same draft PR).
